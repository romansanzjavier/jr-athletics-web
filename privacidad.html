Política de privacidad

Última actualización: octubre de 2026

En resumen

Esta web no recoge datos personales, no usa cookies, no tiene formularios ni analítica y no carga scripts de terceros. Las compras y los pedidos los gestiona Amazon.

1. Responsable

El responsable de este sitio web es el titular indicado en el aviso legal.

2. Datos que recoge esta web

Ninguno. No hay formularios, registro de usuarios, boletín ni herramientas de analítica o publicidad. Tampoco se instalan cookies ni se guarda información en tu navegador. Por eso esta web no muestra un aviso de cookies.

3. Alojamiento

La web está alojada en GitHub Pages, un servicio de GitHub, Inc. Como cualquier servidor, el proveedor de alojamiento puede registrar datos técnicos de la conexión, como la dirección IP, por motivos de seguridad y funcionamiento del servicio. Tienes más información en la declaración de privacidad de GitHub.

4. Tipografías, imágenes y vídeos

La tipografía, las imágenes y los vídeos se sirven desde este mismo dominio. Al navegar por la web no se hacen peticiones a Google Fonts ni a otros servicios externos.

5. Compras en Amazon

Al pulsar «Comprar en Amazon» sales de esta web. La compra, el pago, el envío y las devoluciones los gestiona Amazon, que trata tus datos según su propia política de privacidad. Esta web no recibe tus datos de pago ni de envío.

6. Instagram

El enlace a Instagram te lleva a la cuenta @jr.athleticsfit. Una vez allí se aplica la política de privacidad de Instagram (Meta).

7. Tus derechos

Como esta web no recoge datos personales, no hay datos tuyos que consultar, rectificar o suprimir. Si tienes cualquier duda, puedes escribir al email que figura en el aviso legal. También puedes presentar una reclamación ante la Agencia Española de Protección de Datos (aepd.es).

8. Cambios en esta política

Si en el futuro la web empezara a recoger datos o a usar cookies, esta política se actualizará antes de hacerlo.
